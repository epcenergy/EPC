# EPC Ηλεκτρολόγος – εφαρμογή προσφορών (Φάση 1)

Στατική PWA: χωρίς server, χωρίς λογαριασμό, χωρίς κόστος. Τα δεδομένα μένουν στη συσκευή σου (IndexedDB).

## Τι έχει ολοκληρωθεί (Φάση 1)
Πελάτες, έργα (με καταστάσεις), προσφορές με αυτόματη αρίθμηση (ξεκινά από 2163, ρυθμίζεται), αναλυτική/συνοπτική μορφή από τα ίδια δεδομένα, υπολογισμός κόστους/κέρδους/ΦΠΑ σε ακέραια λεπτά, εκτύπωση/PDF Α4, αποθήκη με ιστορικό κινήσεων και τιμών, έλεγχος διαθεσιμότητας ανά προσφορά, λίστα υλικών προς αγορά, αφαίρεση υλικών μόνο με επιβεβαίωση (μία φορά ανά προσφορά), αντίγραφο ασφαλείας/επαναφορά JSON, offline λειτουργία.

## Τι ΔΕΝ υπάρχει ακόμα
Εισαγωγή CSV τιμοκαταλόγων, AI προτάσεις, διαδικτυακή αναζήτηση τιμών, ξεχωριστή οθόνη εξόδων ανά έργο, ποσοστό κέρδους ανά κατηγορία υλικού. Η φωνητική καταχώριση γίνεται με το 🎤 του πληκτρολογίου του κινητού (δεν δουλεύει offline σε όλες τις συσκευές).

## Δοκιμή στον υπολογιστή
Το Service Worker θέλει http(s) ή localhost:
    cd epc-app && python3 -m http.server 8000
και άνοιξε http://localhost:8000

## Δωρεάν φιλοξενία (GitHub Pages)
1. Φτιάξε δωρεάν λογαριασμό στο github.com και ένα νέο repository (π.χ. `epc`).
2. Ανέβασε ΟΛΑ τα αρχεία του φακέλου (index.html, sw.js, manifest.webmanifest, icon-*.png).
3. Settings → Pages → Branch: main → Save. Η διεύθυνση θα είναι https://ΟΝΟΜΑ.github.io/epc/
(Εναλλακτικά: Cloudflare Pages ή Netlify Drop.) Οι όροι δωρεάν υπηρεσιών μπορεί να αλλάξουν· κράτα αντίγραφα.

## Εγκατάσταση
**iPhone:** άνοιξε τη διεύθυνση στο Safari → κουμπί Κοινοποίηση → «Προσθήκη στην Αρχική Οθόνη».
**Android:** Chrome → μενού ⋮ → «Εγκατάσταση εφαρμογής».
Άνοιξέ την μία φορά με internet για να αποθηκευτεί offline.

## PDF στο iPhone
Προσφορά → «Εκτύπωση / PDF» → στο παράθυρο εκτύπωσης κάνε zoom-out (άνοιγμα με δύο δάχτυλα) στην προεπισκόπηση ή πάτα Κοινοποίηση → «Αποθήκευση στα Αρχεία».

## Ασφάλεια δεδομένων
Η αποθήκευση δεν είναι κρυπτογραφημένη· όποιος έχει πρόσβαση στη συσκευή/browser μπορεί να δει τα δεδομένα. Αν σβηστούν δεδομένα του browser ή χαθεί η συσκευή, χάνονται όλα χωρίς αντίγραφο. Κάνε αντίγραφο εβδομαδιαία (Ρυθμίσεις → Δημιουργία αντιγράφου) και κράτα το σε iCloud/Google Drive.
